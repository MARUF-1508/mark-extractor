# Third-party components

Result Desk uses these projects. Retain their license files and notices when redistributing a packaged app.
PyInstaller collects package data, including the local OCR models, into the distribution.

- RapidOCR: Apache-2.0 — https://github.com/RapidAI/RapidOCR
- Bundled PP-OCR detection/recognition/classification models: PaddleOCR / PaddlePaddle authors, Apache-2.0 — https://github.com/PaddlePaddle/PaddleOCR
- ONNX Runtime: MIT — https://github.com/microsoft/onnxruntime
- pypdfium2: Apache-2.0 / BSD-3-Clause; PDFium and its dependencies have additional notices included with the package — https://github.com/pypdfium2-team/pypdfium2
- OpenCV: Apache-2.0; opencv-python packaging has additional dependency notices — https://github.com/opencv/opencv-python
- NumPy: BSD-3-Clause — https://numpy.org
- Pillow: MIT-CMU — https://python-pillow.github.io
- openpyxl: MIT — https://openpyxl.readthedocs.io
- Python and Tcl/Tk: Python Software Foundation / Tcl/Tk licenses — https://www.python.org and https://www.tcl.tk

The supplied examples belong to their respective authors. They are test inputs, not part of the app bundle.
